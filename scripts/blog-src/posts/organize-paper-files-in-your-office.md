Most offices in Nigeria still run on paper: contracts, staff files, letters, receipts, case files, land documents. The problem is rarely the paper itself. It is that nobody knows exactly where a file is, who took it last, or whether it is still in the building.

A good archive system answers three questions for every file: where it lives, who has it now, and when it is coming back. Here is how to build one.

## Map where paper lives

Before you sort a single file, describe your storage as a set of places, from big to small:

1. **Room.** Records room, MD's office, accounts office.
2. **Cabinet or rack.** Cabinet A, Cabinet B.
3. **Shelf or drawer.** Shelf 1, Drawer 3.
4. **Box.** Box 12, for files in archive boxes.

Give each place a short code and write it on the cabinet or shelf itself. "Records Room, Cabinet B, Shelf 2" becomes `RR-B-2`. Now any file's location can be written in one line.

## Give every file a reference

Each file needs a unique reference that never changes, even if the file moves. A simple pattern works well:

- A prefix for the type: `HR` for staff files, `CL` for client files, `LT` for letters.
- A running number: `HR-0001`, `HR-0002`.

Avoid using names as references. Two staff can share a name, and names get misspelt. The reference goes on the file cover, the label and your register.

## Label the outside clearly

A label should show, at minimum:

- The reference.
- A short title, like "Adebayo T. staff file".
- The storage place it belongs to.

Put labels in the same position on every file, so staff can read them without pulling files out. Boxes need labels on the side that faces out.

## Keep a register

The register is the list of every file: reference, title, where it belongs and its current status. It can be a book, a spreadsheet or an app. Without it, the only way to find a file is to search the shelves.

## Track every check-out

This is where most offices fail. Files leave the records room and never come back. Fix it with a simple rule: **no file leaves without being signed out.**

Record each check-out with:

| Detail | Example |
|---|---|
| File reference | `CL-0145` |
| Taken by | Mrs. Okafor, Legal |
| Date out | 3 November |
| Return by | 10 November |

When the file comes back, record the return. Once a week, check for anything past its return date and follow up. Treat a file nobody can find as **missing** and write that down too, so it does not quietly disappear from memory.

## Scan what you search often

Scanning does not replace the paper archive, but it saves trips to the records room. Start with files people ask for most: contracts, title documents, staff appointment letters. Keep the paper original and note in your register that a scan exists.

Scans are most useful when you can search the text inside them, not just the file name.

## Let a few people manage it

Name one records officer, with a backup. Others can request and return files, but only these people should register new files, move them between places or mark them missing.

## Where to start this week

1. Walk the office and write down every room and cabinet that holds files.
2. Give each place a code and label it.
3. Register your most-used files first, not all of them at once.
4. Start the check-out rule today.

A records room that takes an hour to search costs more than it looks. Once each file has a place, a label and a check-out record, finding one takes minutes.
