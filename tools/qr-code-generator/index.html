QR Code Generator

Choose what the code should hold, then download it.

Your code appears here once you fill in the details.

How to use this tool

  1. Pick a type: link, text, email, phone or Wi-Fi.
  2. Fill in the details. The code updates as you type.
  3. Download it as PNG for print and screens, or SVG for a sharp result at any size.
  4. Scan it with your phone before you print it.

How it works

A QR code is a grid of squares that stores your text in a pattern a camera can read. This page builds the grid in your browser, so what you enter is not uploaded.

Error correction lets a code still scan when part of it is dirty or covered. Higher levels add redundancy and make the code denser. Medium suits most uses.

Keep strong contrast between the code and its background, with the code darker. Light codes on a dark background fail on many scanners.

Example. A link to your site, printed at least 2 cm wide on a flyer, scans reliably from arm's length.

Frequently asked questions

Do these QR codes expire?

No. The code holds your text directly, so it works as long as what it points to still exists. There is no tracking or redirect.

Can I use them on print and signs?

Yes. Download the SVG for large prints, or the PNG for documents and screens. Leave a blank margin around the code.

How do I make a Wi-Fi code?

Choose Wi-Fi, enter the network name and password, and pick the security type. Phones that scan it offer to join the network.

Why does my code not scan?

Check the contrast, print it larger, or raise the error correction. Very long text makes a denser code that needs more size.
