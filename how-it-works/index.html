Hosting Model

No monthly hosting fee for eligible websites

We use GitHub Pages to host eligible simple websites. This allows us to provide hosting without charging a monthly hosting fee.

We can't promise that every future website can be hosted this way. Websites that need server-side processing, databases, authentication, private APIs, or dynamic backend functionality may require a different hosting solution, which is quoted separately.

Domain registration (e.g. www.yourbusiness.com) is separate from the website package unless explicitly included. Elevven11 Studio can handle domain setup for an additional fee.
